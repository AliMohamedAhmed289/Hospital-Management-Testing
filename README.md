# Hospital Management System Testing Framework

## Project Title
Hospital Management System Testing Framework

## Project Description
This project aims to design and implement a complete testing framework for a Hospital Management System covering:

- Manual Testing
- Automation Testing (Java, Selenium WebDriver, TestNG, POM, DDT, Cucumber)
- API Testing (Postman + JavaScript)
- Database Validation (SQL Server)

## Manual Testing Scope
- Preparing Test Plan
- Writing Test Scenarios
- Creating detailed Test Cases using Excel Sheets
- Preparing Requirement Traceability Matrix (RTM)
- Logging Defects in Excel format
- Performing:
  - Smoke Testing
  - Functional Testing
  - Regression Testing
  - Negative Testing

## Automation Testing Scope
- Patient Registration
- Doctor Registration
- Appointment Booking
- Billing and Payments
- Patient History and Reports

## API Testing Scope
- Validate API responses
- Test CRUD operations (Patients, Doctors, Appointments)
- Validate status codes and response body
- Perform negative API testing

## Database Testing Scope
- Validate patient/doctor records
- Verify appointment bookings
- Validate billing transactions
- Check data integrity and consistency

## Technology Stack
- Java
- Selenium WebDriver
- TestNG
- Cucumber
- Postman
- SQL Server
- Excel
